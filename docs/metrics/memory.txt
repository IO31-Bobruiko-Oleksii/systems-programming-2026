== 6. Heap
  heap functions in the image: _malloc_r, _sbrk, _sbrk_r
  _sbrk is reachable: _sbrk <- _sbrk_r <- _malloc_r <- _svfiprintf_r <- vsniprintf <- say <- app_selftest <- main
  _malloc_r is reachable: _malloc_r <- _svfiprintf_r <- vsniprintf <- say <- app_selftest <- main
  newlib-nano calls the allocator from vsnprintf only to grow a buffer it allocated itself
  (asprintf); say() gives it a fixed 160-byte buffer, so the call is never made. The
  measured `heap_used` (STAT mem) must be 0 in every run: that is the proof.
  (calls through pointers are not followed: 8 functions have some)
